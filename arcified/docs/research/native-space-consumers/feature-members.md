## Additional call sites and ordering

- `HistorySidePanelCoordinator` is created through `GetUserDataFactory().CreateInstance` at implementation lines 420 to 423 under `IsSupported()`, but the returned value is not assigned to `history_side_panel_coordinator_`. Resolve the factory/unowned-user-data lifetime before classifying this as retained owned state. Its constructor edge is real; ownership closure is open.
- `browser_elements_` has Views and WebUI variants. Focus has Views, WebUI and stub variants. Side-panel UI, exclusive-access context, find-bar owner and zoom-manager variants are distinct paths. The normal Views path does not cover the WebUI path.
- `lens_overlay_entry_point_controller_` is constructed at 446, but initialized only for normal windows with Lens enabled at 1016 to 1026, after fullscreen/location-bar dependencies. `user_education_` is constructed at 574 and bound to BrowserView at 931 to 933.
- `unload_controller_` is explicitly first-created/last-destroyed. Fullscreen precedes bookmark-bar and window-feature controllers. BrowserActions precedes command controller so initial command-enabled updates are observed. Location model delegate precedes model. Session helper precedes tab-list bridge and extension window controller. Window-feature controller precedes immersive mode. Post-window WebUI exclusive context precedes exclusive access, then WebContents delegate. Download/fullscreen-control depend on exclusive access. Zoom manager precedes coordinator.
- Pre-window teardown runs embedder first; fullscreen-control/download/WebContents delegate release before exclusive access, then WebUI exclusive context. DevTools tears down before contents views vanish. Focus/select-file/UI/color helpers detach before widget death; bookmark delegate is cleared. Contextual tasks shut down before observed immersive/features go away. Sign-in has its own pre-window teardown. Preserve both explicit hook order and reverse member-destruction dependencies. A presentation switch must not rerun these once-only lifecycle hooks.
