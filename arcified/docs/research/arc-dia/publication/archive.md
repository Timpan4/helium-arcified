## User outcome

Provide a searchable archive of closed temporary tabs with their Space and source identity.

Type: implementation. Phase: Core desktop UX.

Disposition: Recommended core integration or verification, with improvements preferred over literal Arc replication.

## Acceptance criteria

- [ ] Close/archive, restore and restore-to-another-Space preserve URL, label and intended placement.
- [ ] Archive and browser history remain distinguishable, with clear permanent deletion controls.
- [ ] Restore does not resubmit forms automatically; empty, deleted, private and corrupt entries have safe behavior.

## Starting point and close proof

The fork currently has an extension prototype. Inspect and reuse Helium's adjacent native features, then integrate or implement the missing contract. Extension tests alone never prove native behavior.

Target platform(s): Linux, Windows and macOS.

Verify the affected interaction in an installed native build on Linux, Windows and macOS. Attach focused behavior and visual evidence, source/build identity, and the named persistence/failure/accessibility cases. Record unavailable-platform checks as open.
